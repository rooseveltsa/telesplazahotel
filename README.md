# Teles Plaza Hotel

Site institucional do **Teles Plaza Hotel** — *"E a sua casa fora de casa"* — hotel em **Águas Lindas de Goiás (GO)**, em frente à BR-070 e a poucos minutos de Brasília.

🔗 **Produção:** https://telesplazahotel.vercel.app/

## Sobre

Single-page institucional, **autocontido** (HTML + CSS + JS em um único `index.html`, sem build), com:

- Identidade visual derivada da logo oficial (azul royal `#243c84` + dourado `#f0b418`)
- Tipografia Fraunces + Inter
- Navegação SPA por hash (`#inicio`, `#acomodacoes`, `#estrutura`, `#localizacao`)
- Dark mode, responsivo (mobile-first) e acessível (WCAG AA)
- Reserva direta via WhatsApp
- **SEO completo:** meta tags, Open Graph, geolocalização, `sitemap.xml`, `robots.txt` e dados estruturados Schema.org (`Hotel` + `FAQPage`)

## Estrutura

| Arquivo | Função |
|---|---|
| `index.html` | Site completo (HTML/CSS/JS embutidos) |
| `og-image.jpg` | Imagem de compartilhamento social (1200×630) |
| `logo-teles.png` | Logo com fundo transparente |
| `robots.txt` / `sitemap.xml` | SEO técnico |

## Deploy

Hospedado na **Vercel** como site estático. Qualquer atualização no `index.html` pode ser publicada com `vercel --prod`.
